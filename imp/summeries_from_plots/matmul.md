For MATMUL, the most influential IMP parameter is again the s/sdist lookahead distance, with the s16 family consistently giving the best results. However, compared to irregular workloads such as SPMV and BFS, the effect is much smaller. The best speedups are 1.059x for L1D + DDR4_1x, 1.063x for L1D + DDR4_2x, 1.048x for L2 + DDR4_1x, and 1.069x for L2 + DDR4_2x. Other parameters such as ipd, dist, addrlen, pt, thr, and sth only provide minor fine-tuning effects. This indicates that MATMUL benefits only modestly from indirect prefetching because its memory access pattern is more regular and less dependent on indirect memory lookahead.
