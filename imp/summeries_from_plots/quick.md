For QUICK, the most influential IMP parameter is the s/sdist lookahead distance. Across all four memory configurations, performance consistently improves from s2 to s8 and reaches its best value with the s16/sdist16 family. The best speedups are 1.146x for L1D + DDR4_1x, 1.143x for L1D + DDR4_2x, 1.104x for L2 + DDR4_1x, and 1.108x for L2 + DDR4_2x. Other parameters such as ipd, dist, addrlen, pt, sth, and aggr have only negligible effects once the s value is fixed. Therefore, QUICK is mainly controlled by prefetch lookahead distance, but its tuning sensitivity is moderate compared to more irregular workloads such as SPMV.
