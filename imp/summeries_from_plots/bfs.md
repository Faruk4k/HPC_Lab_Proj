For BFS, the most influential IMP parameter is the s/sdist lookahead setting. Across all four cache and memory configurations, the s16 family consistently provides the highest speedup, while s2 gives the lowest performance. The effect is strongest for L1D prefetching, especially in the L1D + DDR4_2x configuration, where the best configuration reaches 1.284x, compared to 1.215x for the default IMP. Secondary parameters such as ipd, dist, addrlen, pt, sth, and aggr only provide minor fine-tuning effects once the main s value is fixed. Therefore, BFS performance is mainly controlled by prefetch lookahead distance rather than the other IMP parameters.
