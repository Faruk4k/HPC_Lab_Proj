For MERGE, the most influential IMP parameter is the s/sdist lookahead distance. Across all four configurations, performance improves consistently from s2 to s8 and reaches the best result with the s16 family. The best speedups are 1.159x for L1D + DDR4_1x, 1.171x for L1D + DDR4_2x, 1.123x for L2 + DDR4_1x, and 1.144x for L2 + DDR4_2x. Other parameters such as ipd, dist, addrlen, pt, sth, thr, and aggr have only minor effects once the s value is fixed. Therefore, MERGE is mainly controlled by prefetch lookahead distance, with s16 being the best-performing setting.
