For simple triad, the most influential IMP parameter is the s/sdist lookahead distance, but unlike the irregular benchmarks, the best value is not always s16. In L1D + DDR4_1x, the best configuration is the s8_sth8 family, reaching only 1.045x, while s16 actually hurts performance. In L1D + DDR4_2x and L2 + DDR4_2x, the s16 family gives the best results, reaching 1.240x and 1.364x, respectively. In L2 + DDR4_1x, however, the best result comes from the short-distance s2_sth2 configuration, reaching 1.108x, while the default IMP is below baseline at 0.987x. This shows that simple triad is highly sensitive to the interaction between prefetch distance, cache level, and memory bandwidth
